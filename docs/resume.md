# 简历描述

**安澜 SIEM 检测规则与告警研判系统 | 个人开发项目 | Wazuh / Python / Detection-as-Code**

- 基于 Wazuh 开发 Web 与认证日志解码和检测配置，统一 Apache/Nginx 字段契约，维护 34 条规则，覆盖 SQL 注入、XSS、路径穿越及认证异常等线索，并为 27 条规则配置 ATT&CK 映射。
- 使用 Python 实现离线告警标准化、稳定标识去重与时间窗口归并，按部署、主机、来源及类别隔离事件，输出带规则等级、归并理由和证据位置的 JSON/Markdown 研判报告。
- 设计限定范围、负责人、工单及到期时间的降噪策略，保留被降噪事件与审计记录；建立 XML/字段/引用静态校验、42 项离线回归及跨平台 CI，提供真实 wazuh-logtest 断言入口。

## 表述边界

测试数量是当前本地离线回归结果，不是原生检测通过数。原生断言案例已提供，但原生 Wazuh 与完整集群的结果必须以实际运行证据为准。

不要写生产级 SOC、已上线企业、高准确率、误报率降低百分比、完整一键部署或 AI 自动响应。演示归并数量只是固定合成样本，不可作为真实业务收益。
